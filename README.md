# Pharmacy Tech Study

## Project folders

- `assets/css/` — shared website styling
- `assets/js/` — shared navigation, quiz, results, and practice logic
- `indications/` — the 21 medication indications; each folder contains its landing page, quiz page, and medication data
- `practice/` — More Practice hub plus one folder per practice quiz
- `terminology/` — terminology reference pages
- `index.html` — main medication quiz page
- `results.html` — medication quiz personal bests
- `extra-results.html` — More Practice personal bests

## 201 Medication Mastery

Located in `practice/medication-mastery/`.

The quiz contains all 201 medications and asks two questions per medication:
1. Brand name from the generic name
2. Indication for that same medication

Medication order is randomized, but each medication's two questions stay together.
